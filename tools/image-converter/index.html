Drop images here, paste from the clipboard (Ctrl+V), or

PNG, JPEG, WebP, GIF, BMP, AVIF and SVG in; up to 25 MB and 50 megapixels each. Everything is converted locally in your browser.

JPEG has no transparency, so transparent areas always get this colour.
Tokens: {name} {w} {h} {format} {n} {date}. The extension is added automatically.

Metadata: re-encoding through a canvas removes EXIF/GPS/colour-profile data. The EXIF rotation is applied to the pixels first, so photos keep their orientation. Animated GIF/WebP/APNG files keep only their first frame. “Same as input” keeps the original file when re-encoding would make it bigger (and nothing is resized).
