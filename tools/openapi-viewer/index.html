Privacy and CORS: the request is made directly from your browser to the address you enter (it is not sent through this site). That server will see your IP address, and it must allow cross-origin requests (CORS), otherwise the browser blocks it: in that case download the file and use "Open file". Only http(s) URLs up to 10 MB are accepted; remote $ref links inside the document are never fetched.

This is a viewer and documentation generator only: there is no "Try it out" button and no request is ever sent to the API described.
