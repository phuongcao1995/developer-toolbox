PBKDF2

PBKDF2 runs HMAC thousands of times so that each password guess is expensive. The defaults follow current OWASP guidance: 600,000 iterations for SHA-256 and 210,000 for SHA-512.

Salt

A salt is not a secret key. It is stored next to the hash and makes two users with the same password get different hashes, which defeats precomputed tables. Use a new random salt of 16 bytes or more for every password.

Adding a salt to a fast hash like SHA-256 does not make it safe for passwords. For new server-side systems, Argon2id, scrypt or bcrypt are also good choices; browsers don't provide them natively.

Encrypt / decrypt

Encrypt text with AES-256-GCM. The result is a JSON block containing everything needed to decrypt it except your password or key.

Operation
Secret
Key derivation settings

AES-GCM

AES in Galois/Counter Mode encrypts and authenticates in one step. A 128-bit tag is appended to the ciphertext; if a single bit of the data or its metadata changes, decryption fails instead of returning corrupted text.

IV and salt

Every encryption uses a new random 12-byte IV, and password mode also uses a new 16-byte salt. Both are stored in the output. They are not secret, but an IV must never be reused with the same key.

Your data is only as safe as your password. A short or reused password can be guessed offline no matter how strong the cipher is.

Encrypt / decrypt with key

Quick AES encryption with a text key, compatible with CryptoJS AES.encrypt(text, key) and OpenSSL. Output is a single Base64 string.

Legacy format. It has no tamper detection and derives the AES key with one round of MD5, so a short key can be guessed offline. Use it to interoperate with existing CryptoJS data; use Encrypt / decrypt for anything new.
Operation

Format

AES-256-CBC with PKCS#7 padding. The result is Base64 of Salted__, an 8-byte random salt, then the ciphertext, so the same text and key give a different result each time.

Interoperability

Decrypts with CryptoJS.AES.decrypt(text, key) and openssl enc -d -aes-256-cbc -md md5 -a -A.

A wrong key usually fails with an error, but CBC cannot always tell, so check that decrypted text looks right.
