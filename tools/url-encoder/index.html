Which one should I use?

Component (encodeURIComponent) encodes everything except A-Z a-z 0-9 - _ . ! ~ * ' ( ). Use it for a single query value, path segment or key: a&b=c becomes a%26b%3Dc.

Full URL (encodeURI) keeps URL structure characters : / ? # [ ] @ ! $ & ' ( ) * + , ; = untouched and only escapes unsafe ones such as spaces and non-ASCII. Use it on a whole URL, never on a value.

Form encoding is the application/x-www-form-urlencoded flavour used by HTML forms: spaces become + instead of %20.
