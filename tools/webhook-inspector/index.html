A static web page cannot receive real webhooks. There is no server behind this tool, so nothing on the internet can send requests to it. Demo mode lets you compose requests and record them locally as simulated ones (great for learning what webhook payloads look like). External service mode reads real requests captured by a third-party inspector such as webhook.site.
