NotesEverything runs in your browser. DOCTYPE external entities are refused and entity expansion is limited, so untrusted documents are safe to paste. "Strip comments" applies to Format and Minify; mixed content and xml:space="preserve" are never re-indented.

Output

Default-namespace elements cannot be addressed by plain name in XPath 1.0: use *[local-name()='book']. Declared prefixes (see Info) work as written.

Attributes become @name keys, text becomes #text next to attributes or child elements, repeated elements become arrays and empty elements become null. The conversion uses the Input editor and writes to the Output editor. JSON keys that are not valid XML names are rewritten (a warning lists them).
