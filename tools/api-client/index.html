Off: Authorization, Cookie, API-key headers and Auth-tab secrets are saved as [redacted]. Variables are saved as {{names}}, never as their values. Bodies are cut at 64 KB. Pinned entries survive Clear.

Params and the URL stay in sync: editing either updates the other. Only the query string is rewritten. Use {{name}} for variables.

Some headers (Host, Origin, Cookie…) are forbidden and set by the browser; they are dropped silently. Variables work in names and values.

Added to the request:

Values may use {{variables}}; mark the variable as secret in the environment so it is masked and excluded from exports. An explicit Authorization header in the Headers tab takes precedence. Auth is applied at send time and is not saved in history unless "Save sensitive values" is on. Saved collection requests keep what you type here (in localStorage), so prefer a {{variable}}.

Credentials. include sends and stores cookies on cross-origin requests, but the server must then answer with Access-Control-Allow-Credentials: true and a specific (not *) Access-Control-Allow-Origin, otherwise the browser blocks the response. omit never sends cookies.

Requests are sent directly from your browser: there is no proxy or backend. CORS rules apply, so servers without CORS headers cannot be called, and browsers hide some headers (Cookie, Origin, Set-Cookie…).

Scripting is unsupported. Postman-style pre-request and test scripts are not run (and are skipped on import) because arbitrary script cannot be safely sandboxed in a static page. Use {{variables}} and the dynamic variables {{$uuid}}, {{$timestamp}}, {{$isoTimestamp}}, {{$randomInt}} instead.
